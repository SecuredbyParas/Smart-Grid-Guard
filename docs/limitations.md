- **Simulated only.** All telemetry, devices, IP addresses and users are generated by `src/generate_data.py`. Nothing connects to a real meter, utility network or SCADA system, and the project has no ability to send commands to any device.
- **Synthetic data is easy.** Injected anomalies are much bigger than normal noise. Real attacks can be subtle and real data is messier (weather, holidays, new customers, missing readings).
- **Clean baseline assumed.** The first 10 days are treated as normal. If a real meter was already tampered with, the baseline would learn the wrong behaviour.
- **Fixed rules and thresholds.** The z-score threshold and admin scoring weights were picked by hand and tuned on the same synthetic data, so the 0 false alarms result is optimistic.
- **Simple correlation.** Events are linked only by substation and a time window. It does not model the real network topology or attacker steps.
- **Severity is a heuristic.** The score formula is not a validated risk model; analysts should review every incident.
- **Hourly resolution.** Faster attacks (seconds or minutes) would not be visible.
